⚠️ Third-party cookies required for apps.mypurecloud.com.au
The login popup saves the auth token as a cookie. When the iframe is embedded in a different origin (e.g. GitHub Pages), browsers block this as a third-party cookie and the iframe stays stuck on "Waiting for credentials...".

Fix (Edge / Chrome): Settings → Privacy → Cookies → Sites that can always use cookies → add [*.]mypurecloud.com.au.
Symptom: Popup closes automatically, iframe never loads. In iframe DevTools context: document.cookie === "".
